# Strudel AI Composer

Веб-приложение: вы описываете музыку словами или голосом, AI-агент генерирует код на [Strudel](https://strudel.cc/) (live-coding музыкальный фреймворк), и код сразу исполняется в браузере с визуализацией pianoroll.

- **Текст** → OpenAI (GPT-4o-mini) генерирует Strudel-код (стриминг, эффект печатания)
- **Голос** → запись с микрофона (MediaRecorder) → Groq Whisper (бесплатно) → текст команды
- **Звук и визуализация** → `@strudel/web`: pianoroll, scope, игра сразу после генерации

## Установка

```bash
npm install
cp .env.example .env   # вставьте свои ключи
npm run dev
```

Откроется `http://localhost:5173`. При первом клике разблокируется звук (политика браузеров для AudioContext).

## API-ключи

Возьмите `.env.example`, переименуйте в `.env` и заполните:

| Переменная | Где получить | Назначение |
|---|---|---|
| `OPENAI_API_KEY` | https://platform.openai.com/api-keys | генерация Strudel-кода (GPT-4o-mini) |
| `GROQ_API_KEY` | https://console.groq.com/keys | распознавание голоса (Whisper, бесплатно) |
| `OPENAI_BASE_URL` *(необязательно)* | совместимый прокси | если регион блокирует api.openai.com |
| `GROQ_BASE_URL` *(необязательно)* | совместимый прокси | аналогично для Groq |

Ключи используются только на стороне сервера разработки: запросы идут через прокси Vite (`/api/chat` → OpenAI, `/api/transcribe` → Groq), на фронтенд не попадают.

## Как пользоваться

1. Опишите музыку в поле «Команда» — текстом или кнопкой «🎤 Голос»
2. «▶ Исполнить» — агент сгенерирует код и сразу запустит музыку с визуализацией
3. Панель «Код Strudel» редактируема: правьте вручную и жмите «▶ Играть этот код»
4. «⏹ Стоп» — остановить, «🗑 Сброс» — очистить всё

### Примеры команд

- «драм-партия в стиле Queen с мощным басом»
- «спокойная мелодия на пианино в тональности ля минор, 80 BPM»
- «добавь к текущему коду хай-хэты на каждую восьмую»
- «сделай бас тяжелее и замедли темп»

## Структура

```
├── index.html            # главный экран
├── src/
│   ├── main.js           # точка входа
│   ├── strudel-engine.js # initEngine / evaluateCode / stop / reset / unlockAudio
│   ├── agent.js          # OpenAI через прокси Vite, stream: true
│   ├── voice.js          # MediaRecorder + Groq Whisper
│   ├── ui.js             # кнопки, лог, поток генерации
│   └── styles.css        # тёмная тема
├── vite.config.js        # прокси /api/chat, /api/transcribe
└── .env.example          # шаблон ключей
```

## Сборка

```bash
npx vite build
```

> Примечание: барабанные сэмплы (dirt-samples) загружаются лениво при первом исполнении кода с GitHub-CDN Strudel; синтезаторы работают без них. Для генерации кода и голоса нужен интернет и валидные ключи.
