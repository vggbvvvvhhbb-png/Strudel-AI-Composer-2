# STRUDEL-FACTS — измеренные факты о движке

> Файл генерируется скриптом `scripts/probe-strudel-facts.mjs`. Правь руками —
> правки будут стёрты. Источник истины — измерение, не документация.

- **Пакет:** `@strudel/web` версии **1.3.0**
- **Измерено:** 2026-11-19T01:48:12.012Z
- **API бандла:** 1017 экспортов, 1173 методов паттерна
- **Способ:** Node без браузера (UMD-бандл `@strudel/web`, `setStringParser(mini)`) — события считаются настоящим `queryArc`.
- **Звучание:** да — рендер в headless-Chromium (системный Chrome/Edge)

## Правила чтения этого файла

1. **«экспорт»** — имя есть среди `Object.keys(bundle)`.
2. **«метод»** — имя есть в `Pattern.prototype`.
3. **«исполняется»** — код с этим именем отработал без ошибки в `queryArc`.
4. **«звучит»** — рендер дал слышимую громкость (LUFS-I ≠ −∞).
5. Отсутствие в таблице = **не измерено**, а не «нет».

### Что из этого следует

- `duckorbit` — метод паттерна, исполняется. `duckOrBit` (другой регистр) — **не существует**: движок отвечает «s(...).duckOrBit is not a function». Значит опечатка в регистре — тихая поломка, а не «почти работает».
- Имена семейства `duck*` регистрозависимы: `duckattack`, `duckdepth`, `duckonset` — строчными.
- `detunepower` в 1.3.0 отсутствует — использовать нельзя.

## 3. Аккорды

| Написание | без .voicing(): событий | с .voicing(): событий | с .voicing(): нот | вывод |
|---|---|---|---|---|
| `Fmaj7` | 1 | 0 | 0 |  |
| `F^7` | 1 | 5 | 5 |  |
| `FM7` | 1 | 5 | 5 |  |
| `Fm7` | 1 | 5 | 5 |  |
| `G7` | 1 | 5 | 5 |  |
| `A:min` | 1 | 0 | 0 |  |
| `Am` | 1 | 5 | 5 |  |

- **`chord(...)` без `.voicing()` не даёт нот** — 1 событие(й), нот 0. Такая партия молчит.
- `rootNotes()` — отдельная проверка: 0 событий. Это **не** замена `.voicing()`.

## 4. Темп

- В Node-харнессе `setCpm`/`setcps`/`setbpm` **не доступны**: экспортов нет, `initStrudel` падает с «AudioContext is not defined».
- Это не баг движка: `initStrudel` регистрирует control-функции (темп) в браузере,
  а Node-стенд его не зовёт. Проверка темпа — только рендером.
- Рендер с `setCpm(60/4)`: событий 4, длительность 8 с;
  с `setCpm(240/4)`: событий 4, длительность 8 с.

## 6. Сигнал без .seg()

- `note("c4").lpf(sine.range(200,2000))` — 1 событие(й): значение сигнала читается один раз на ноту, фильтр не «открывается».
- то же с `.seg(16)` — 16 событий: непрерывная огибающая.

## 7. Как перепроверить

npm run probe:facts -- --no-audio   # без браузера
