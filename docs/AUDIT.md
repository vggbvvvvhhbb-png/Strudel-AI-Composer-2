# Аудит проекта Strudel AI Composer

Дата: 2026-11-06. База: коммит `477ee1b`, ветка `main`, 13 файлов / 2665 строк.

## 1. Структура на момент аудита

```
index.html            — единственный экран (панель команды + textarea кода + лог)
src/main.js           — точка входа (9 строк)
src/strudel-engine.js — обёртка @strudel/web: init/evaluate/stop/reset/unlockAudio
src/agent.js          — fetch /api/chat (прокси Vite), stream: true, stripMarkdown
src/voice.js          — MediaRecorder → /api/transcribe (прокси Vite → Groq Whisper)
src/ui.js             — монолит: кнопки, лог, статусы, голос
src/styles.css        — тёмная тема, токены инлайн в :root
vite.config.js        — dev-прокси /api/chat → OpenAI, /api/transcribe → Groq
.env.example, .gitignore, README.md, package.json, package-lock.json
```

## 2. Что работает

- Strudel-движок: инициализация `@strudel/web` 1 раз, `evaluate`, `hush`, разблокировка
  AudioContext по клику (`src/strudel-engine.js`).
- Визуализация: `pianoroll/scope/fscope/spectrum` перехватываются и рисуются в canvas
  внутри контейнера (`patchVisuals`, src/strudel-engine.js:26) — рабочее нестандартное решение.
- Стриминг LLM: SSE парсится вручную, код печатается по мере прихода, markdown
  обрезается (`src/agent.js:21-76`).
- Сэмплы dirt-samples грузятся лениво, при неудаче синтезаторы остаются рабочими.
- Тёмная тема, адаптив до 860px, `prefers-reduced-motion` учтён.

## 3. Что сломано / отсутствует (разрыв с целевым ТЗ)

- **Нет продакшн-API.** Ключи работают только через dev-прокси Vite; `vite build`
  даёт статику без бэкенда — в проде генерация не работает вовсе.
- Модель захардкожена `gpt-4o-mini` (src/agent.js:37), не настраивается.
- Нет: валидатора и автофикса, режима improve с diff, микшера по партиям,
  транспорта BPM/тональность, пресетов и истории, шаринга ссылкой, записи WAV,
  тестов, docs, deploy-файлов.
- Редактор — `textarea` без подсветки; все canvas сваливаются в один контейнер
  без привязки к партиям; состояние (mute/solo/gain) не существует.
- Логика размазана: `ui.js` держит и бизнес-флоу, и рендер; `agent.js` смешивает
  транспорт SSE и промпт.

## 4. Дубли и мусор

- Крупных дублей нет (кодовая база маленькая). Два параллельных канала статусов:
  `log()` и `setStatus()` в ui.js — заменяются на toast + статус-строку.
- `patchVisuals` в движке дублирует то, что в целевой архитектуре должен делать
  слой `ui/pianorolls` — выносится при редизайне.

## 5. Секреты

- `git log -p -S"sk-"`: единственный коммит — ключей нет, в `.env.example`
  только плейсхолдеры `sk-...`.
- `grep -rn "sk-|gsk_|API_KEY"`: совпадения только в README (названия переменных)
  и vite.config.js (чтение `process.env`) — реальных ключей в дереве нет.
- Реальный API-ключ был прислан владельцем **в чат** (не в репозиторий). Он будет
  записан только в локальный `.env` (в `.gitignore`), в код и коммиты не попадёт.
  Рекомендация: после завершения работ ротировать ключ, т.к. он фигурировал в чате.

## 6. Принятые решения

- **@strudel/web вместо отдельного @strudel/repl** — пакет уже подключён, работает
  и включает тот же repl+webaudio+draw; замена на голый `@strudel/repl` сломала бы
  рабочий конвейер evaluate/визуализации без выигрыша в функциональности.
- **Голосовой модуль удаляется** (src/voice.js, кнопка, роут /api/transcribe) —
  решение владельца: «голосом пользоваться не буду», приоритет — функционал и красота.
  Multer/Groq в сервер не включаются.
- **Express-сервер на 127.0.0.1:3001** отдаёт `dist/` и `/api/*`; Vite-прокси
  в dev остаётся только для `/api` → 3001.
- Микшер реализуется модификацией кода партий (mute `_$PART:`, solo, `.gain(x)`)
  парсером на токенизаторе с юнит-тестами.

## 7. Риски, известные заранее

- CSP/сеть: сэмплы тянутся с `raw.githubusercontent.com` — их надо явно разрешить
  в helmet CSP; AudioWorklet требует `blob:` и `'wasm-unsafe-eval'`.
- SSE за nginx требует `proxy_buffering off` и заголовков без `Connection: keep-alive`.
- Парсинг партий Strudel-кода хрупок — покрывается тестами на токенизаторе.
- Запись WAV зависит от AudioWorklet (Safari капризен) — degrade: кнопка скрывается
  при отсутствии поддержки.
