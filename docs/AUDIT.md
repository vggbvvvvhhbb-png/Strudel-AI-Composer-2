# Аудит проекта «Strudel AI Composer» (2026-11-06, до фазы A)

Исходное состояние: один коммит `477ee1b`, 13 файлов, Vite + vanilla JS + `@strudel/web@1.3.0`.

## Что работает
- **Сборка** `vite build` — проходит, бандл ~644 kB (Strudel-движок, ожидаемо).
- **Движок** `src/strudel-engine.js`: одноразовая инициализация `initStrudel`, `evaluateCode`,
  `stop/reset` через `hush()`, разблокировка звука по клику (аудио-гейт в `index.html`).
- **UI** `src/ui.js` + `index.html`: поле команды, кнопки Исполнить/Стоп/Сброс, лог, рендер `pianoroll`.
- **Стили** `src/styles.css`: тёмно-синяя тема, моношрифт, адаптивная сетка.

## Что сломано / отсутствовало
- **Ключи на фронте**: `src/agent.js` ходил на OpenAI/Groq напрямую с ключом из запроса
  пользователя — ключи обязаны жить только на сервере.
- **Несуществующие эндпоинты**: `/api/chat` и `/api/transcribe` в `vite.config.js` вели в никуда;
  `src/voice.js` дублировал логику `agent.js` и был мёртвым кодом.
- **Нет стриминга**: ответ LLM приходил целиком, эффект «живой печати» отсутствовал.
- **Нет валидации кода**: битый код от LLM падал в консоль без диагностики и автофикса.
- **Нет микшера, транспорта (BPM/key), пресетов, истории, шеринга, записи WAV** — в рамках фаз B/C/D.
- **`.env` в репозитории отсутствовал**, `README` обещал `npm run dev` без серверной части.

## Что дублировалось
- HTTP-клиент LLM был продублирован в `agent.js` и `voice.js` → оба удалены,
  единый клиент вынесен в `server/llm/client.js` + `src/api/client.js`.

## Секреты
- `git log -p -S"sk-"` и `grep -rn "sk-\|gsk_\|API_KEY"` — реальных ключей в коде и истории НЕТ
  (только плейсхолдеры в `.env.example`). Присланный в чате ключ записывается владельцем в
  локальный `.env` (в `.gitignore`); в код не попадает.
- Добавлены `scripts/check-secrets.js` (regex `sk-`/`gsk_`) и pre-commit хук.

## Целевая архитектура (фазы A–D)
Node-прокси на 127.0.0.1:3001 (Express, helmet, rate-limit, zod) → SSE-генерация →
валидатор (статика + тихий прогон в REPL) → автофикс ≤2 → REPL `evaluate()` с пианороллами.
Голосовой модуль исключён по решению владельца (2026-11-06): «голосом пользоваться не буду».
