## Почему CI был красным — две настоящие причины

**1. Контейнер поднимался без `HOST=0.0.0.0`.**
`server/config.js` по умолчанию слушает `127.0.0.1` — это осознанно, чтобы
сервер не торчал наружу без явного разрешения. `docker-compose.yml` это
учитывает, а `docker run` в CI — нет. Внутри контейнера сервер слушал
только loopback, опубликованный порт `-p 3001:3001` был недостижим снаружи,
и health-check не проходил **никогда**. Образ при этом собирался
исправно — падал шаг «Образ поднимается и отвечает».

**2. Тест пула падал на свежей машине.**
`data/samples/audio/` в git не входит (`.gitignore`), на CI каталога нет,
а тест писал туда WAV без создания каталога → `ENOENT`. Локально проходило,
потому что каталог у тебя уже был создан.
