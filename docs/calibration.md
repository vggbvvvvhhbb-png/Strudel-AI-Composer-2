# Калибровка скора по оценкам человека

Скор «музыкальности» — прозрачная эвристика, а не истина. Он полезен как
обратная связь: модель получает конкретные замечания и правит код. Но если
скор систематически расходится с человеческим восприятием, он врёт и тянет
модель не туда. Поэтому скор калибруется на размеченных примерах.

## Что калибруем

Модельный скор — взвешенная сумма десяти критериев (см. `server/music/score.js`).
Калибровка подбирает **веса критериев** так, чтобы порядок треков по модельному
скору совпадал с порядком по оценке слушателя. Сами целевые диапазоны
(`server/music/references.js`) калибруются вручную — по тем же примерам.

Метрика качества — корреляция Спирмена (ранговая корреляция): она не зависит
от масштаба оценок и устойчива к « outliers».

## Процедура сбора данных (слепой A/B)

1. **Соберите примеры.** 20–30 треков, поровну удачных и провальных.
   Хороший источник — код, который сгенерировал сам проект: там есть и явные
   удачи, и типичные провалы. Готовый стартовый набор — `docs/calibration-template.json`.
2. **Сделайте оценки слепыми.** Слушатель не должен видеть модельный скор и
   знать, какой пример «известно хороший». Иначе он выравнивает оценки
   по ожиданиям, а не по звучанию.
3. **Оцените по единой шкале** от 1 до 10: 1 — невозможно слушать, 10 — не
   оторваться. Оценивать нужно то, что слышно: строй, ритм, аранжировку,
   напряжение. Не «нравится ли мне жанр» — это отдельная ось.
4. **Заполните `humanRating`** в JSON и запустите калибровку.

## Запуск

```bash
cp docs/calibration-template.json docs/calibration-data.json
# вписать humanRating в docs/calibration-data.json
node scripts/calibrate.mjs
```

Скрипт:

- посчитает для каждого примера разбор и скор;
- выведет текущую корреляцию Спирмена с оценками человека;
- жадно переберёт веса критериев и покажет, какие изменились;
- выведет готовый блок весов для вставки в `CRITERIA` в `server/music/score.js`;
- покажет скор и число замечаний по каждому примеру.

Свой набор данных: `node scripts/calibrate.mjs путь/к/данным.json`.

## Как читать результат

| Корреляция | Что это значит |
|---|---|
| ≥ 0.6 | Скор надёжно отражает восприятие, можно опираться на него в цикле правок |
| 0.3–0.6 | Скор частично полезен: оставить, но не полагаться на него как на истину |
| < 0.3 | Скор почти не связан с оценками: пересобрать цели или сменить набор примеров |

Если корреляция низкая, но примеров всего 8 — это ещё не приговор: на малой
выборке корреляция скачет. Сначала доведите выборку до 20–30, потом делайте выводы.

## Чего калибровка не делает

- Не превращает скор в «объективную истину». Это по-прежнему набор эвристик.
- Не заменяет прослушивание. Финальную проверку качества всё равно делает человек.
- Не трогает референсные диапазоны стилей автоматически — только веса критериев.
