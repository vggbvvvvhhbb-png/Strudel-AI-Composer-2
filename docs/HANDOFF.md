# HANDOFF — состояние проекта на конец сессии

*Обновлено 14 ноября 2026, сессия «Composition IR + символьный оракул»*

## Сделано в этой сессии

**Composition IR (спринт S2, основное).**
- `src/ir/` — 10 модулей: схема (Zod), планировщик по тексту, эмоция,
  гармония, аранжировка, грув, палитра, компилятор, трансформации, PRNG.
- `src/oracle/` — символьный оракул: быстрые события из IR, метрики, линтер
  с типизированными трансформациями, скор, канарейки, поиск, критик.
- API `/api/music/ir/{plan,transform,search,critique}` + панель «🧩 План
  композиции» в интерфейсе: описание → план → код, кнопки «мрачнее /
  светлее / энергичнее / спокойнее» с видимой дельтой, поиск и починка.
- Документы: `docs/IR.md`, `docs/ORACLE.md`, решения D-046…D-054.

**Найдено и починено 9 реальных дефектов** (все — с доказательством):

| Дефект | Симптом | Где |
|---|---|---|
| PRNG без финализатора | 46 % значений в одном десятом интервала, среднее 0.68 | `src/ir/prng.js` |
| Сдвиг свинга выбирал лишние шаги | при unit = 2 сдвигались и 3, 7, 11, 15 | `src/ir/groove.js` |
| Рисунок ударных не повторялся по тактам | бас «плавал» мимо кика, lock 5 % вместо 50 % | `src/oracle/ir-events.js` |
| В матрице ролей не было снейра | ни один трек не имел бэкбита | `src/ir/arrangement.js` |
| Регистр роли игнорировался компилятором | `shiftRegister` был пустой трансформацией | `src/ir/compiler.js` |

## Следующие 3 действия

1. **Подключить LLM-планировщик к IR.** Схема готова к JSON-schema; LLM должен
   выдавать IR, а не код. Плюс ≤2 ремонтных ретрая с текстом ошибки Zod.
   Критерий приёмки: 10 промтов → 10 валидных IR, код исполняется движком.
2. **Baseline-0 (спринт S0.2).** Корпус из 60 промтов, сплит 36/12/12 по хэшу,
   заморозить sha256. Нужен, чтобы «лучше» вообще было что-то, чему измерять.
3. **Дорожка H: 10 пар.** «Тиндер»-страница и первые 10 человеческих суждений.
   Без меток ни Taste Model, ни честная приёмка невозможны.

## Блокеры

- **Метки.** Это главный дефицит. Пока человек не сравнил треки между собой,
  символьный скор остаётся гипотезой, а утверждение «микс стал лучше» —
  бездоказательным.
- **Лицензии сэмплов.** 42 сэмпла из 44 тянутся с GitHub-CDN, не вендорены,
  тексты лицензий по файлу не сверены (S1.C). Для публикации — блокер.
- **Домен.** sslip.io временный; свой DNS не настроен.

## Что нужно от владельца

1. **≈20 пар в день по ≈6 минут** — без этого цикл измерений не запускается.
2. **Лимиты $** для LLM: на трек, на «лучше», суточный cap. Пока не заданы —
   бюджеты не зашиты.
3. **Рецензенты** (1–3 друга) — нужны минимум двое для приёмки по §7.2.
