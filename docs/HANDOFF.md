**Починка:** тест `rag-route` был красным («expected 152 to be 148») — он

ломает тест).

**Найдено и НЕ починено (нужно владельцу):** диск C: заполнен — свободно
**≈1 МБ из 194 ГБ**. Из-за этого три теста падали на `ENOSPC`. Источник
заполнения найден: **134 каталога `playwright_chromiumdev_profile-*` в `%TEMP%`
(≈2.4 ГБ)**, из них 35 создано за последние сутки. Измерено: корректно
закрытый браузер профиля **не** оставляет — текут процессы, умирающие без
закрытия Chromium. Очистить из сессии нельзя (политика блокирует удаление вне
рабочего каталога). **Что сделать:** удалить `%TEMP%\playwright_chromiumdev_profile-*`
и перенести `TEMP`/`TMP` на диск со свободным местом; ворота в этой сессии
прогнаны с `TEMP` на F: (свободно 102.8 ГБ).

## Правила, которые нельзя нарушать

- Тесты зелёные на каждом чекпоинте; `npm run gate` — одна команда.
- Ключи — только в env; `check:secrets` зелёный.
- `check:taste` не обходить; выученная цель не входит в скор до гейта людей.
- Каждый новый сэмпл/шрифт/датасет — запись в `docs/LICENSES.md`.
- Серверный GPU не покупаем (D-089). Локальные вычисления — можно (D-097).
- Не выдавать имитацию за агента: если тулз не вызывается по-настоящему —
  это чат с декорациями, гейт не пройден.
- «Нет данных» ≠ 0: оценка помечается оценкой, неизвестная цена говорится
  словами, а не нулём (D-102).
- Каждые ~4 часа: атомарные коммиты + `docs/SESSION_REPORT.md` + `docs/HANDOFF.md`.
