# HANDOFF — состояние проекта на конец сессии

*Обновлено 16 ноября 2026: фазы A0, A, B, C закрыты; фаза D закрыта по
механике («Учитель» D-111, style-mining D-112, мотив и L1-метрики); фаза E
закрыта по механике и живому замеру — паспорт управляет планом, найденный
сэмпл звучит в рендере (D-119), живой гейт E 10/11 + 1 «нет данных» (LLM).*

## Где мы сейчас

Фазы **A0 (фундамент), A (помощник-агент), B (local-first) и C (100 дорожек
и опера) закрыты**. Фаза **D (мелодический мозг)** сделана по механике:
движок мотивов, общая тема трека, фразировка A|A'|B|A'', L1-метрики
мелодии, измерительный рефайн «Учитель» поверх compose (D-111) и
библиотека измеренной статистики стилей из паспортов разбора (D-112).
Слепого A/B «до/после» на людях по-прежнему не было.

Фаза **E («Охотник»)** закрыта по механике и живому замеру: поиск сэмплов
в Freesound с двойным фильтром лицензий (D-114), паспорт звука и локальный
пул (D-115), **паспорт в план и сэмпл в рендере (D-119)**: измеренный тон
задаёт тональность, темп атак — BPM, плотность — ритм партии HUNTER_1;
неизмеренное честно «нет данных». WAV пула звучат в локальном рендере
(same-origin раздача, `poolSamples`, поле в fingerprint). Тулзы агента:
`freesound_search` → `sample_passport` → `pool_search` →
`compose_spec(sampleId)` → `compile` → рендер. Живой гейт E: 10/11 +
1 «нет данных» за 6.0 с (бюджет ≤180 с); LLM-шаг не измерен — relay-ключ
без баланса (402), новый ключ блокируется Cloudflare (403).

Потолок в 12 партий снят: ключ `parts.roles` — идентификатор партии
(`VIOLIN_1`), роль стала атрибутом. Трек из **66 дорожек** собирается из
плана детерминированно (`src/music/expand.js`), рендерится локально без
клиппинга и проходит гейт L0.

Помощник — это настоящий агентный цикл «план → инструмент → наблюдение →
ответ» с SSE, деградацией без ключей, памятью разговора и панелью в студии.
Тяжёлое считается на машине владельца: локальный демон `local/` с очередью
на диске — задача переживает убийство процесса.

Гейт проекта — одна команда: `npm run gate` (14 шагов, включая
`licenses:pool`). Гейты фаз: `npm run gate:a` (15/15 офлайн, 20/20 с живым
поиском), `npm run gate:b` (10/12, две строки — «нет данных») и
`npm run gate:e` (9/9 офлайн; `--live` 10/11 + 1 «нет данных»). Решения
сессии: D-097…D-119.

Следующее — **рабочий LLM-ключ** (баланс relay или base URL нового ключа),
затем **фаза F: UX студии** и человеческий гейт качества (слепой A/B).

## Что НЕ сделано и почему (честно)

1. **Разделение на стемы не измерено** — на этой машине нет `numpy`, `torch`,
   `demucs`. Демон честно показывает `analysis.available = false`. Нужно
   Python-окружение владельца: инструкция в `local/README.md`.
2. **«Бит-в-бит» для рендера не подтверждено** — локальный и серверный WAV
   различаются на 1 LSB в смеси осциллятора и сэмпла (D-104, E-019). Допуск
   проекта (maxAbsDiff ≤ 1e-4) соблюдён, `renderFingerprint` совпадает точно.
3. **Публикация заблокирована** — 2 банка сэмплов без подтверждённой лицензии
   (`dirt-samples`, `shabda:piano`), 219 имён. `npm run gate -- --release` —
   красные ворота. **Нужно решение владельца** (D-099, `docs/PARKING.md` §3).
4. **Выученная цель не принимается гейтом** — живых пар 10 (нужно 60),
   закрыто промптов 5 (нужно 50). Механика зелёная, данных не хватает.
5. ~~Полный проход гейта A с интернетом не измерен~~ — **измерен**: живой
   режим с реальным поиском 20/20 (`0bc6751`), цена поиска видна в usage.
6. **Цена LLM с реальным ключом не измерялась** — панель показывает «Цена
   не измерена», а не ноль (D-102). Цена поиска измерена (`3605566`).
   Relay-ключ возвращает 402 «Insufficient balance», новый ключ владельца
   блокируется Cloudflare (403) на `api.apinex.bond` — нужно решение
   владельца: пополнить баланс или дать рабочий base URL.
7. **Один инструмент из таблицы гайда не реализован:** `ab_eval` (нужен
   живой рецензент). `freesound_search` готов (D-114).
8. ~~Живой проход «Охотника» end-to-end не измерен~~ — **измерен** (D-119):
   живой гейт E 10/11 + 1 «нет данных» за 6.0 с, найденный сэмпл слышен в
   рендере. Осталось «нет данных»: LLM-шаг композитора (ключ без баланса) —
   агентный цикл с настоящей моделью на сценарии «Охотника» не измерен.
9. **Фронт не подключён к демону** — демон, маршруты и измерения готовы;
   кнопка «считать локально» в студии — это фаза F (UX).
10. **Оркестровая раскладка стала настоящей, но не «умной».** Голоса стоят в
    своих регистрах и играют **одну общую тему** (дивизи, своя фраза в каждой
    секции). Не сделано: тема не знает гармонии (гармония по-прежнему
    строится из корней аккордов), и ни одного прослушивания человеком
    «до/после» не было — числа выше это измерители, а не оценка качества.
11. **Мастер по умолчанию не годится для оркестра** — порог −20 dBFS
    компрессора жмёт материал на 5 дБ (см. `docs/SESSION_REPORT.md` §1.4).
    В демо заданы оркестровые настройки; дефолт студии стоит поменять.

## Правила, которые нельзя нарушать

- Тесты зелёные на каждом чекпоинте; `npm run gate` — одна команда.
- Ключи — только в env; `check:secrets` зелёный.
- `check:taste` не обходить; выученная цель не входит в скор до гейта людей.
- Каждый новый сэмпл/шрифт/датасет — запись в `docs/LICENSES.md`.
- Серверный GPU не покупаем (D-089). Локальные вычисления — можно (D-097).
- Не выдавать имитацию за агента: если тулз не вызывается по-настоящему —
  это чат с декорациями, гейт не пройден.
- «Нет данных» ≠ 0: оценка помечается оценкой, неизвестная цена говорится
  словами, а не нулём (D-102).
- Каждые ~4 часа: атомарные коммиты + `docs/SESSION_REPORT.md` + `docs/HANDOFF.md`.
