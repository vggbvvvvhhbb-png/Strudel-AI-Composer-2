## Что НЕ сделано и почему (честно)

1. **Публикация заблокирована** — 2 банка сэмплов без подтверждённой лицензии
   (`dirt-samples`, `shabda:piano`), 219 имён. `npm run gate -- --release` —
   красные ворота. **Нужно решение владельца** (D-099, `docs/PARKING.md` §3):
   оставить/заменить `dirt-samples`; для `shabda:piano` — ключ Freesound API
   или исключить банк.
2. **Выученная цель не принимается гейтом** — живых пар 10 (нужно 60),
   закрыто промтов 5 (нужно 50). Механика зелёная, данных не хватает. Так и
   должно быть: `check:taste` не обходится.
3. **Цена LLM с реальным ключом не измерялась** в этой сессии — ключей в репозитории
   нет. Покрыто тестом. Факт: нет данных.
4. **Агентного контура нет** — фаза A не начата.

## Что делать дальше (фаза A — помощник-агент)

Донор агентного контура лежит в `.scratch/shveyka-igolka` (клон, не копировать
слепо — читать и адаптировать). Карта — в `GLOBAL_SESSION_PROMPT.md` §8 и
Приложение B.

1. **Конвейер «план → тулзы → наблюдение → рефлексия»** с SSE: события шагов и
   текста раздельные (панель показывает шаги отдельно от ответа).
2. **Инструменты** (каждый — с тестом, лимитом и схемой): `web_search`,
   `web_fetch`, `library_search`, `compose_spec`, `compile`, `edit_ir`,
   `render_local`, `usage_report`. Позже — `freesound_search` (фаза E) и
   `deep_dive` (только по явному запросу: 14–27 минут).
3. **Честная деградация:** нет ключа поиска → агент отвечает по каталогу и сам
   говорит «Интернет недоступен». Тест на деградацию обязателен.
4. **Учёт расхода** виден в панели: цена каждого вызова из `recordUsage`.

Гейт A: запрос «найди в интернете, что такое phonk drift, и сделай бит в этом
стиле» агент проходит сам — ищет → читает → строит план → компилирует → играет;
каждый шаг виден в панели; без ключа поиска не падает, а деградирует.

## Перед фазой C — не забыть

- Спайк источника истины (IR vs TrackSpec) → решение **D-100** с числами, а не
  мнением. Если мост дороже 5 инженерных дней — откат к TrackSpec.
- **Перебазировать критерий `parts`** в `server/music/references.js` / `score.js`:
  мягкая цель 4–7 партий (вес 10) иначе рубит трек из 100 дорожек.

## Правила, которые нельзя нарушать

- Тесты зелёные на каждом чекпоинте; `npm run gate` — одна команда.
- Ключи — только в env; `check:secrets` зелёный.
- `check:taste` не обходить; выученная цель не входит в скор до гейта людей.
- Каждый новый сэмпл/шрифт/датасет — запись в `docs/LICENSES.md`.
- Серверный GPU не покупаем (D-089). Локальные вычисления — можно (D-097).
- Не выдавать имитацию за агента: если тулз не вызывается по-настоящему — это
  чат с декорациями, гейт не пройден.
- Каждые ~4 часа: атомарные коммиты + `docs/SESSION_REPORT.md` + `docs/HANDOFF.md`.
