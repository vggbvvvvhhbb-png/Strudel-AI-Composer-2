# HANDOFF — состояние проекта на конец сессии

*Обновлено 15 ноября 2026, сессия «Прорыв», фаза A закрыта (гейт A — 15/15).*

## Где мы сейчас

Фазы **A0 (фундамент) и A (помощник-агент) закрыты**. Помощник — это больше не
«один промпт → код»: это настоящий агентный цикл «план → инструмент →
наблюдение → ответ» с SSE, деградацией без ключей, памятью разговора и
панелью в студии.

Гейт проекта — одна команда: `npm run gate` (13 шагов, 56.3 с). Гейт фазы A
отдельно: `npm run gate:a` (15/15, отчёт `docs/evidence/agent/gate-a.json`).
Решения сессии: D-097…D-100 (A0) и D-101, D-102 (фаза A).

Следующая фаза — **B: local-first** (рендер, сепарация и анализ на машине
владельца; LLM остаётся облачным, D-097).

## Что НЕ сделано и почему (честно)

1. **Публикация заблокирована** — 2 банка сэмплов без подтверждённой лицензии
   (`dirt-samples`, `shabda:piano`), 219 имён. `npm run gate -- --release` —
   красные ворота. **Нужно решение владельца** (D-099, `docs/PARKING.md` §3):
   оставить/заменить `dirt-samples`; для `shabda:piano` — ключ Freesound API
   или исключить банк.
2. **Выученная цель не принимается гейтом** — живых пар 10 (нужно 60),
   закрыто промптов 5 (нужно 50). Механика зелёная, данных не хватает. Так и
   должно быть: `check:taste` не обходится.
3. **Полный проход гейта A с интернетом не измерен** — ключа `EXA_API_KEY` в
   репозитории нет. Измерена честная деградация: агент не падает, отвечает по
   каталогу и говорит об этом. Факт: нет данных.
4. **Цена LLM с реальным ключом не измерялась** — ключей в репозитории нет.
   В панели вместо нуля показывается «Цена не измерена» (D-102).
5. **Два инструмента из таблицы гайда не реализованы:** `freesound_search`
   (фаза E — только CC0/CC-BY) и `ab_eval` (требует живого рецензента; слепое
   сравнение человеком, автоматикой не заменяется).
6. **История диалога живёт в панели, а не на диск** — диалог сохраняется в
   открытой студии; серверного хранения проектов пока нет.

## Что делать дальше (фаза B — local-first)

1. **Локальный рендер** (`render_local`): WAV на машине владельца, метрики и
   `renderFingerprint` измеряются локально, не на сервере.
2. **Сепарация и анализ — локально** (D-097): серверный GPU не покупаем.
3. **Проверить, что локальный путь даёт тот же `renderFingerprint`**, что и
   серверный: иначе детерминизм разъезжается между машинами.
4. **Стоимость ночи** (`/api/stats`) — число, а не оценка; нужен реальный ключ.

## Перед фазой C — не забыть

- Спайк источника истины (IR vs TrackSpec) → решение **D-100** с числами, а не
  мнением. Если мост дороже 5 инженерных дней — откат к TrackSpec.
- **Перебазировать критерий `parts`** в `server/music/references.js` / `score.js`:
  мягкая цель 4–7 партий (вес 10) иначе рубит трек из 100 дорожек.

## Правила, которые нельзя нарушать

- Тесты зелёные на каждом чекпоинте; `npm run gate` — одна команда.
- Ключи — только в env; `check:secrets` зелёный.
- `check:taste` не обходить; выученная цель не входит в скор до гейта людей.
- Каждый новый сэмпл/шрифт/датасет — запись в `docs/LICENSES.md`.
- Серверный GPU не покупаем (D-089). Локальные вычисления — можно (D-097).
- Не выдавать имитацию за агента: если тулз не вызывается по-настоящему — это
  чат с декорациями, гейт не пройден.
- «Нет данных» ≠ 0: оценка помечается оценкой, неизвестная цена говорится
  словами, а не нулём (D-102).
- Каждые ~4 часа: атомарные коммиты + `docs/SESSION_REPORT.md` + `docs/HANDOFF.md`.
