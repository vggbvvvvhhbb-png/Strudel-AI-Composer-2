# Taste Model — выученная цель

*Обновлено 2026-11-17 · этап 0 сессии Timbre Palette: данные перемерены
по `server/data/*.jsonl` и `docs/evidence/taste/gate.json` (прежняя версия
от 14.11 показывала 0 пар / 0 промтов — устарела).*

## Что это

Модель сравнения пар: `P(A лучше B) = σ(w · (x_A − x_B))`, где `x` —
стандартизованный вектор признаков (L0 звук + L1 структура).
Обучается на человеческих парах: человек слушает два варианта и говорит,
какой лучше; модель учится, **какое отличие** между ними важно.

## Проверка (leave-prompt-out CV)

Пары одного промта не независимы, поэтому проверка оставляет целый промт
целиком: «полезна ли модель на новом промте?»

| величина | значение |
|---|---|
| живых пар в проверке | 10 (нужно ≥60) |
| промтов | 5 (нужно ≥50) |
| CV-accuracy | — (механика проверена на синтетике: 1, CI 0.9124…1) |
| 95% CI (Уилсон) | считается верно (проверка механики: 0 из 10 → [0, 0.2775]) |
| базовая линия «случайность» | 0.5 |

## Вердикт

**Модель не допущена в скор.** Ручные веса продолжают работать, помеченные «не проверено на людях».

Причины (факт из `check:taste`, humanGate: pending):

- человеческих пар 10 < 60 — модель не используется
- закрыто промтов 5 < 50
- CV-accuracy на живых данных не измерялась (мало данных)

Условия допуска (бриф §7.4):

1. человеческих пар ≥ 60;
2. CV-accuracy ≥ 60%;
3. нижняя граница 95% CI выше лучшей базовой линии;
4. модель не вырождена (веса не нулевые).

## Что нужно от владельца

Открыть `/tinder.html` и послушать пары: **20 пар ≈ 6 минут**.
Метки сразу становятся обучающими примерами (признаки считаются в
браузере тем же DSP-ядром), а `npm run taste:train` переобучает модель.
