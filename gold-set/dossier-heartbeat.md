## 7. Что из этого можно проверить нашим пайплайном

**Анализ (без стемов):**
- Темп по секциям (окна 4 с, onset-density) → H5, H7.
- Онсет-паттерн перкуссии (1/8 vs 1/16 vs триоль) → H2.
- Pitch-track баса, детекция слайдов → H3.
- Реверберационные метрики (RT60, wet/dry) → H4, H8.
- Динамика/crest factor, корреляция бочки с мастером → H6.
- Жанровая классификация / embedding-близость → H7.

**Стемы (нужен source separation):**
- Отделить вокал → проверить, лежит ли сэмпл под ним → H1, H9.
- Отделить бас → честная pitch-трасса 808, а не артефакт сепаратора → H3.
- Отделить перкуссию → онсет-детализация и триоли → H2.

**Только ручная разметка владельца:**
- H1 (сэмпл «Hometown Glory») — автоматически не верифицируется без чистого референса; нужна ручная сверка с источником.
- Источник интерполяции, давшей кредит Madonna/Pharrell Williams (H1-adjacent) — только вручную через publisher-информацию.
