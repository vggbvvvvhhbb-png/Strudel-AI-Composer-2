## 7. Что из этого можно проверить нашим пайплайном

**Анализ (без стемов):**
- Темп по секциям (окна 4 с) + проверка дрейфа → H1, H2.
- Онсет-паттерн перкуссии (позиции бочки/хэтов) → H1, H4.
- Self-similarity / поиск повторяющихся фрагментов → H3.
- Динамика/crest/цеф → H8.
- Жанровая классификация → H10.

**Стемы (нужен source separation):**
- Перкуссия → offbeat-хаус-паттерн, шумовой клэв → H4, H7.
- Бас → синтез vs сэмпл, диапазон → H5.
- Сравнение спектра басового слоя с «чужой» записью → H3.

**Только ручная разметка владельца:**
- **Тональность** — внешних данных нет вообще.
- **Какой именно фрагмент «I get inspired» использован** — нужен оригинал SackJo22 для сверки.
- **BPM 127** — единственный источник — автор трека.
