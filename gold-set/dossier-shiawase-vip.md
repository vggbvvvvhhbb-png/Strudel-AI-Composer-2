**Итог — ключевое отличие от остального набора.** Это **единственный трек набора без slowed-семейства** среди треков с вариантами: VIP **короче** оригинала (×0.835), при этом **тот же BPM 150** (Beatport для VIP — 150; Shazam для оригинала — 149; Chordify для оригинала — 150). Значит, VIP — это **пересборка/нарезка с сохранением темпа**, где вырезаны части (например, укорочено интро или дроп-секции), а не растяжение времени. Гипотеза «slowed = time-stretch» на этом треке **неприменима** — вместо неё проверяется гипотеза «VIP = edit (удаление секций при неизменном темпе и тоне)».

**Косвенное подтверждение:** Genius перечисляет «Shiawase (VIP) Is A Remix Of Shiawase» и одновременно Monstercat называет релиз «Instinct» (Monstercat Instinct — лейбл для «club/EDM-версий»), что типично для пересборки с добавлением нового материала и/или переработкой структуры. ?

## 7. Что из этого можно проверить нашим пайплайном

**Анализ (без стемов):**
- Темп по секциям (окна 4 с) → H1, H6.
- Cross-similarity версий + детекция «вырезанных» участков → H2.
- Реверберационные метрики (RT60, wet/dry), эхо-импульсы → H5.
- Динамика/crest/цеф/LUFS по версиям → H8.
- Анализ тональности → H9.

**Стемы (нужен source separation):**
- Вокал → чанки, ре-питчинг, «pitched up chops» → H4.
- Лид/бас → pitch-track (абсолютные ноты, тональность), саб-характер → H3, H7, H11.
- Перкуссия → онсет-детализация, 4-on-the-floor vs half-time → H6.
- Сравнение энергий по стемам original ↔ VIP → H10.

**Только ручная разметка владельца:**
- **Тональность** — внешние источники дают энгармонические варианты записи; разрешается только измерением.
- **BPM 149 vs 150** — расхождение в 1 BPM неразличимо без измерения; при 150 BPM разница в 1 BPM не влияет на сетку.
