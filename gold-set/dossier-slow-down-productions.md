## 3. Саунд-дизайн-разведка

**Факты:**
- **Авторские теги прямо называют «живой» характер записи:** `live`, `guitar`, `drums`, `vocals`. ✓ Именно это делает трек кандидатом на критерий (b) «живая гитара + барабаны».
- **Жанровый самоярлык — 2-step / jazz / hip-hop / funk / jungle** (теги `2_step`, `jazz`, `hip_hop`, `funk`, `jungle`) при темпе **144 BPM** и теге `bpm_140_145`. Это внутренне противоречивая комбинация: 2-step/jungle обычно 160–175, jazz/funk 90–130. ≈ Возможно, теги — это «вкусовая» разметка автора (он же поставил теги `marokko`, `amsterdam`, `south_america`, `forensic`), а 144 BPM — фактический темп записи. Либо 144 BPM — это half-time-восприятие при 288/2=144. **Требует измерения.**
- **Вокал в треке заявлен дважды:** тег `vocals` + «Nice vocals 4nsic crew» в описании + «Featuring Sol from 4nsic». ✓
- **Авторское имя группы связано с темпом/названием:** «Slow Down Productions» + теги `slow`, `slow_down`, `slow_down_productions` — трек, вероятно, изначально сделан как «медленный» материал. ≈ (этимология, не факт о звуке)
- **Трек помечен как ремикс** (тег `remix`), при этом на странице нет строки «Uses samples from» для другого трека, кроме указанной выше. ✓

**Не найдено в открытых источниках:**
- **Интервью slowdownproductions / Sol (4nsic)**, описание студии и записи — не найдено.
- **Reddit / Gearspace / Equipboard / Tape Op / Sound on Sound** — по этому треку записей нет.
- **Сведения о том, играется ли гитара живым исполнителем или это запись сэмпла/петли** — не найдено. Для критерия (b) это ключевой вопрос, и разрешить его может только измерение (детекция «живых» нестабильностей: джиттер атаки, разброс длительностей нот, микрофонный шум, отсутствие циклической сетки).

## 7. Что из этого можно проверить нашим пайплайном

**Анализ (без стемов):**
- Темп по секциям, проверка кратности → H5, H9.
- Self-similarity / детекция повторяющихся фрагментов → H3, H4.
- Динамика/crest/цеф → H8.
- Жанровая классификация → H9.

**Стемы (нужен source separation):**
- Перкуссия → «живая» vs «сэмпловая» (тембр, вариативность, room) → H2.
- Бас → живой бас vs 808 → H7.
- Вокал → пол, микрофонная близость, слои → H6, H11.
- Клавиатура → MIDI vs акустика → H10.

**Только ручная разметка владельца:**
- **Тональность** — внешних данных нет.
- **Разрешение противоречия «не содержит сэмплов» vs «Uses samples from: ABC VERSE by FORENSIC»** — вручную со сверкой обеих записей.
- **Факт «живой записи»** (критерий b) — вручную: спектральная непрерывность и вариативность атаки.
