## 7. Что из этого можно проверить нашим пайплайном

**Анализ (без стемов):**
- Темп по секциям, swing-детекция → H5.
- Self-similarity / детекция «швов» и повторяющихся фрагментов → H1, H7.
- Динамика/crest/цеф → H10.
- Pairwise cross-similarity по цепочке ccMixter → H9.

**Стемы (нужен source separation):**
- Вокал → F0, тембр, микрофонная близость → H4.
- Rhodes → тембр электропиано → H2.
- Гитара → живое vs сэмпл → H3.
- Бас → наличие басовой линии → H8.
- Выравнивание слоёв по сетке (jitter) → H6.

**Только ручная разметка владельца:**
- **Тональность** — внешних данных нет.
- **Наличие настоящей акустики/настоящего Rhodes** (критерий (c)) — вручную: тембр и микрофонные признаки.
- **Отсутствие стемов на странице трека** — если владельцу нужны стемы для автотестов, их придётся искать отдельно (в `docs/LICENSES.md` упоминание стемов не подтверждено).
